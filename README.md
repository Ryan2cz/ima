# AmbiSeis manual

Website: https://ryan2cz-ima.readthedocs.io/zh-cn/latest/

The source page is docs/index.html. Read the Docs publishes it using .readthedocs.yaml.
Pushes to main notify Read the Docs through the repository webhook.

Local update workflow: replace the source HTML in D:\imatest and run publish.cmd.
The same source is copied into ima-ready for manual upload to Tencent ima.
The repository is public because Read the Docs Community requires a public source repository.
